OPTIONAL PORTRAITS
==================

Drop 96x96 PNG files here to replace the built-in placeholder portraits:

    dino_saurus.png
    pterax.png
    judge.png

They are loaded from /assets/portraits/<id>.png at runtime and snapped to the
four-color palette automatically. The game is fully playable with ZERO asset
files present — if a PNG is missing, a placeholder (initials + snout
silhouette) is drawn instead.
